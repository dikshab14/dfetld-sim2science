# appendix_linearization — empirical linearization study (paper appendix, Fig. panels (a) and (b))

The controlled study behind the paper's claim that statistical
linearization costs little: a one-dimensional nonlinear simulator whose MMD
posterior can be computed **exactly on a grid**, so the derivative-free
approximation can be measured against a reference with no Monte Carlo
error of its own.

Data are generated by `y = theta* + alpha*theta*^3 + xi` and the fitted
simulator is `x = theta + alpha*theta^3 + xi`, with `xi ~ N(0, sigma^2)`.
The parameter `alpha` moves the forward map continuously from affine
(`alpha = 0`) to strongly nonlinear. Defaults: theta* = 0.5, sigma = 1,
N = 100 observations, prior theta ~ N(0, 2^2), beta = 100, M = 20
particles, J = 50 simulations per particle, 30 400 steps, 10 seeds.

Two samplers are compared on the **same** MMD target, so their difference
isolates statistical linearization and nothing else:

- **ALDI (exact gradient)** — It uses the *closed-form*
  MMD gradient, so it makes no simulator calls at all. It is not a
  baseline that could be run on a real simulator; it bounds what any
  sampler of this target could achieve.
- **DF-ETLD** (ours) — the same dynamics with the Jacobian replaced by
  the empirical parameter--output cross-covariance.

## Run

```
python run_experiment.py --full     # ~1.5 h, 10 seeds
python run_experiment.py --demo     # minutes: same sweeps, 4 seeds, shorter chains
#   --only A  or  --only B          # regenerate a single figure
```

A **built-in unit test runs first** in both modes: at `alpha = 0` the
forward map is affine, statistical linearization is exact
(Proposition 1), and DF-ETLD must match the exact-gradient reference. If
that fails, something is wrong with the implementation and no other
number should be trusted.

Writes to `outputs/`:

- `bias_vs_nonlinearity_normalized.png` — **appendix figure panel (a)**:
  W1 distance to the exact posterior, divided by the exact posterior's
  sd, against alpha in {0, 0.05, 0.1, 0.25, 0.5, 1}. The normalisation is
  what makes the y-axis mean the same thing at every alpha, since the
  posterior itself sharpens as alpha grows.
- `bias_vs_ensemble_size.png` — **appendix figure panel (b)**: the same
  error against ensemble size M in {5, 10, 20, 50}, at three nonlinearity
  levels.
- `bias_vs_nonlinearity.json`, `bias_vs_ensemble_size.json` — the numbers
  behind both panels (mean, sd and s.e.m. over seeds, per method), so the
  figures can be restyled without re-running the dynamics.

## What the numbers say

At `alpha = 0` the two samplers are indistinguishable (0.021 vs 0.022
posterior sd), which is Proposition 1 holding empirically. At `alpha = 1`
the exact-gradient error stays at about 0.021 posterior sd while DF-ETLD
rises to 0.142 — a measurable cost, but still below one seventh of a
posterior standard deviation in a deliberately nonlinear stress test.
Panel (b) shows the gap narrowing as M grows.

## Design choices that keep the measurement clean

- **Warm start from the exact posterior.** Both samplers are initialised
  from i.i.d. draws of the grid posterior (inverse-CDF sampling), so what
  is measured is *stationary* bias: a sampler with the correct invariant
  measure stays at the finite-sample floor, a biased one drifts to its
  own stationary state.
- **One dataset per seed, shared.** Within a seed both samplers see the
  same data, the same bandwidth (median heuristic on that dataset,
  frozen), and the same reference posterior; only their internal
  randomness differs.
- **A monotone cubic map.** `g(theta) = theta + alpha*theta^3` is
  monotone for all alpha >= 0, so the reference posterior stays unimodal
  and W1 measures linearization bias rather than a mode being missed.
  (The quadratic variant in `model.MAP_KIND` is non-injective and its
  mirror mode enters the prior already at alpha ~ 0.25.)
- **Error bars are s.e.m. over seeds**, since the figures plot means.
