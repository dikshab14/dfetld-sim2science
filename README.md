# Derivative-Free Ensemble Transform Langevin Dynamics (DF-ETLD)

Code for the paper *"Derivative-Free Ensemble Transform Langevin
Dynamics: Robust Inference for Misspecified Simulators"*.

DF-ETLD samples MMD-Bayes generalized posteriors for likelihood-free
simulators using only forward simulator calls: the simulator Jacobian in
the MMD gradient is replaced by an empirical parameter–output
cross-covariance (statistical linearization; Sec. 2 and Proposition 1 of
the paper). The core sampler is `common/dfetld.py` (numpy-only); everything else is benchmarks and baselines.

## Dependencies

Python >= 3.9 with `numpy`, `scipy`, `matplotlib` (see
`requirements.txt`; exact versions used for the paper are pinned there
as comments). No GPU, no external SBI packages.

```
pip install -r requirements.txt
```

All data are synthetic and generated by the code itself from fixed
seeds; there are no external datasets to download.

## Layout

| Directory | Paper result | Entry point |
|---|---|---|
| `common/` | the DF-ETLD sampler (Sec. 2), MMD machinery, shared figure style | imported by the experiments |
| `exp1_l96/` | Sec. 3.1 stochastic Lorenz '96: **Table 1**; appendix `es_per_timestep_l96.png` | `run_l96.py` |
| `exp2_contamination/` | Sec. 3.2 misspecified location model: **Fig. `contamination_posterior_grid.png`**; appendix `contamination.png` | `run_posterior_grid.py`, `run_contamination.py` |
| `exp3_sir/` | Sec. 3.3 misspecified SIR: **Fig. `sir_posteriors_es_credible.png`**, **Table 2**; appendix `sir_observed_series.png` | `run_sir.py`, `calibrate_beta_es.py`, `run_sir_es.py` |
| `appendix_linearization/` | Appendix "Empirical linearization study": `bias_vs_nonlinearity_normalized.png`, `bias_vs_ensemble_size.png` | `run_experiment.py` |

Each experiment directory carries its own `README.md` with the model,
the exact run commands, the methods compared, and the conventions that
make that comparison fair.

Each experiment's `outputs/` directory contains the committed results the paper
was built from — the exact JSON files behind the tables and the exact
PNG files included in the manuscript — so every reported number can be
checked, and figures restyled, without re-running inference. Only
paper-relevant outputs are committed; re-running a script regenerates
them (plus a few extra diagnostics) in place.

## Reproducing the paper's results

Every runner is deterministic given its seed arguments (defaults are the
paper's seeds) and takes `--outdir` to write elsewhere. `--demo` runs a
fast smoke version where noted. Runtimes below are single-process on an
Apple M5 CPU (the paper's hardware); no experiment needs more than a few
GB of memory.

### Table 1 and the appendix energy-score figure (Lorenz '96)

```
cd exp1_l96
python run_l96.py            # ~2.5 h; --demo for a minutes-scale check
```

Table 1's RMSE / nRMSE columns are `summary.<method>.rmse` and
`summary.<method>.nrmse_all` in `outputs/results_l96.json`
(`dfr` = DF-ETLD, `adk` = adSGLD-KS, `ad` = adSGLD-ES, `abc` = SMC-ABC
raw, `abcs` = SMC-ABC summaries). The time column is
`outputs/timings_l96.json` (per-method wall-clock measured on one
observation set at production settings, single process, same hardware).
The appendix figure is `outputs/es_per_timestep_l96.png`.

### Contamination figures (misspecified location model)

```
cd exp2_contamination
python run_posterior_grid.py   # ~25 min -> contamination_posterior_grid.png
python run_contamination.py    # ~25 min -> contamination.png (appendix)
```

`run_posterior_grid.py` produces the main-text posterior grid
(standard Bayes | DF-ETLD | adSGLD-ES; varying eps in row 1, varying z
in row 2) and calibrates the learning rates once on clean data
(written to `outputs/contamination_posterior_grid_config.json`).
`run_contamination.py` reads those calibrated rates and produces the
appendix mean-error-vs-eps figure (4 methods). Run the grid first.

### SIR figure, Table 2, and the appendix observed-series figure

```
cd exp3_sir
python run_sir.py            # ~22 min: DF-ETLD, SMC-ABC, adSGLD-KS
python calibrate_beta_es.py  # seconds: Bayes-factor-matched beta_ES
python run_sir_es.py         # ~45 min (4 parallel chains x 16k steps)
```

The main-text posterior figure is
`outputs/sir_posteriors_es_credible.png`. Table 2 reads: DF-ETLD error
from `outputs/results.json` (posterior mean vs truth) and its time from
`outputs/cost_table.json`; adSGLD-ES error/time from
`outputs/results_es.json` (converged: 4 chains x 16 000 steps); SMC-ABC error/time from
`results.json` / `cost_table.json`. The appendix observed-series figure
is `outputs/sir_observed_series.png`, written by `run_sir.py`.

### Appendix linearization study

```
cd appendix_linearization
python run_experiment.py --full             # ~1.5 h, 10 seeds
```

Figure panel (a) is `outputs/bias_vs_nonlinearity_normalized.png`
(W1 to the exact grid posterior, divided by the exact posterior sd) and
panel (b) is `outputs/bias_vs_ensemble_size.png`. A built-in unit test
runs first: at alpha = 0 the forward map is affine, statistical
linearization is exact (Proposition 1), and DF-ETLD must match the
exact-gradient ALDI reference. `--demo` gives a noisier minutes-scale
version of the same sweeps.

## Method keys in results files

Short method keys index the results JSON/npz files and the plotting
style table: `dfetld`/`dfr` = DF-ETLD (ours), `adsgld_ks`/`adk` = adSGLD
on the kernel score, `adsgld_es`/`ad` = adSGLD on the energy score,
`abc`/`abcs` = SMC-ABC (raw / summaries), `aldi` = the appendix study's
exact-gradient reference, `bayes` = standard Bayes. See
`common/style.py` for the full key.

## Conventions that keep the comparisons fair

- **Shared targets where a sampler comparison is claimed.** DF-ETLD and
  adSGLD-KS use the same scoring rule, the same weight (beta = w·n) and
  the same bandwidth, so any gap between them is the sampler, not the
  posterior.
- **Learning rates are calibrated, not chosen.** exp2_contamination
  fits w once on clean data so every posterior matches standard Bayes'
  width at eps = 0; exp3_sir's kernel-score beta = 10 is set by credible-interval
  coverage on well-specified datasets, and the energy-score beta by
  Bayes-factor matching against it (`calibrate_beta_es.py`).
- **Bandwidths: median heuristic over simulator draws, frozen** — never
  adapted during sampling, so bandwidth adaptation cannot confound a
  method comparison.
- **Convergence.** Each method runs to its own
  convergence and its cost is reported; per-method simulator-call counts
  are recorded in the output JSONs.

## Baseline notes

- adSGLD is a reimplementation. exp1_l96 uses exact forward
  sensitivities through the RK4 integrator (finite-difference verified);
  exp3_sir uses central finite differences.
- The appendix study's ALDI (analytic MMD gradient) and
  exp2_contamination's standard Bayes are tractable-model
  references that bound what any simulation-based method could achieve,
  not competitors on budget.
